# End-to-End Agentic AI Workflow Automation System

This project is an End-to-End Agentic AI Workflow Automation System. It takes a user's natural language query, classifies the intent, routes it to the correct tool, executes it, and returns a response, all within a single conversational interface.

## Folder Structure
- `data/`: Contains datasets, including `tasks.json`.
- `models/`: Stores machine learning models and embeddings.
- `tools/`: Individual tool implementations (e.g., summarizer, sentiment analyzer).
- `agent/`: Core agent logic including intent classifier, pipeline orchestrator, and memory management.
- `api/`: FastAPI backend setup and main entry points.
- `ui/`: Gradio user interface components.
- `logs/`: System and application logs.
